## Execution Order

### 1. DVDRental Benchmark

```bash
cd paper_final/dvdrental/
```

**Data:** Already present in `data/` (15 CSVs, ~2.8 MB total).

**Run the pipeline:**
1. Open `Sieve_GNN.ipynb`
2. Run **Cell 1** - Main Sieve-GNN pipeline
   - Reads CSVs from `./data/`
   - Generates `sieve_workers.py`, `schema_final.json`, `relationships.csv`, `data_quality_profile.csv`, `erd.png`
   - Prints PK results (expect 14/15 correct, 93.3%)
   - Prints FK results (expect TP=17, FP=3, FN=1, P=85.0%, R=94.4%, F1=0.895)
3. Run **Cell 2** - Multi-seed robustness test (seeds: 42, 123, 256, 789, 1024)
   - Expect zero variance across all 5 runs
4. Run **Cell 3** - Heuristic-only ablation
   - Expect identical results to full pipeline (0 delta)
5. Run **Cell 4** - IND baseline comparison
   - Expect IND: TP=9, FP=26, FN=9, P=25.7%, R=50.0%, F1=0.340

**Run standalone IND baseline (alternative to Cell 4):**
1. Open `ind_baseline.ipynb`
2. Run the single cell - produces full IND baseline results

### 3. Enterprise CRM Note

Earlier internal drafts referenced a licensed V2 Technologies CRM dataset. That
enterprise case study is **not** part of the current reproducible submission in
`paper_final/` and is therefore excluded from the headline evidence in
`main.tex`.

Why it is excluded from the paper's main results:

1. The licensed CSVs are not redistributed in this workspace.
2. The current `paper_final/` reproducibility pack does not ship a runnable V2
   dataset folder.
3. There is no bundled DDL-grounded evaluation path comparable to the public
   benchmark rows.
4. Prior V2 claims depended on internal expert review rather than a fully
   reproducible public benchmark harness.

For the current manuscript, the defensible scope is the public benchmark set
(DVDRental, TPC-H, TPC-DS note, and the Chinook-derived synthetic dataset).

## Compiling the Paper

```bash
cd paper_final/
```

The paper uses the PeerJ CS LaTeX template (`wlpeerj` document class).

**Install the template (if not already available):**
- Download from: https://www.overleaf.com/latex/templates/peerj-latex-template/ptjwrgqkfzbs
- Or install via CTAN: `tlmgr install peerj`
- Place `wlpeerj.cls` in `paper_final/` or your LaTeX path

**Compile:**
```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Or use Overleaf: upload `main.tex`, `sample.bib`, and `wlpeerj.cls`.

## Notes

- All notebooks use `CONFIG['folder'] = './data'` - they expect a `data/` subfolder in the same directory.
- `sieve_workers.py` is auto-generated by Cell 1 of each notebook (embedded as WORKER_CODE). Do not need to copy it separately.
- The `sql_ddl.sql` files contain the DDL ground truth used for PK/FK evaluation. Required for both notebooks and `ind_baseline.py`.
- `generate_tpch_data.py` only needs to run once. After that, `data/` persists.
- Legacy internal notes may still refer to a V2 enterprise CRM case study. That
   case is intentionally excluded from the current manuscript because it is not
   reproducible from the shipped `paper_final/` artefacts.
